# Life in Pink 🌸

**Life in Pink** is a visually appealing, front-end only e-commerce website dedicated to all things pink! The website is designed to provide a fun, aesthetic shopping experience focused on pink-themed products. Perfect for users who love a pink-centric shopping vibe.  

---

## 🌷 Features

- **Pink-Themed UI:** Entire website follows a consistent pink color palette for a cheerful and cohesive look.
- **Product Showcase:** Display a variety of pink-themed products in a grid layout.
- **My first web** Being my first ever website it surely needs correction.
- **Interactive Elements:** Buttons, hover effects, and product cards are designed for a fun user experience.
- **Front-End Only:** No backend integration; ready to be paired with any API or static data.

---

## 🎨 Technologies Used

- **HTML5** – Semantic and structured markup
- **CSS** – Stylish and responsive layouts
- **Google Fonts & Icons** – For aesthetic typography and icons
